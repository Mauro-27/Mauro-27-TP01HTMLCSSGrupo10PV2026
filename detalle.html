Curso Inicial de HTML para Estudiantes

Proyecto orientado a enseñar a los alumnos las bases de HTML para crear páginas web educativas.

Categoría: Programación

Fecha de inicio: Sábado 11 de Abril de 2026

Autores del proyecto:

  • Barrientos Lucas Nahuel
  • Campos Mauro Ismael
  • Chauque Gabriel Horacio
  • Robles Alexander Alan
  • Rocha Erika Abigail

Los objetivos a realizar son:

El objetivo es que los estudiantes puedan crear diversas páginas web utilizando buenas prácticas de progamación. Aprenderán sobre la estructura básica de HTML y las etiquetas semánticas necesarias para derrallorar el proyecto.

Los estudiantes trabajarán en equipo para desarrollar un sitio web de una plataforma de proyectos educativos, donde tendrán que decidir el diseño y responsabilidades de cada uno.

Huerta Escolar Automatizada

Trabajo educativo que integra sensores y tecnología para mejorar el riego y el control de una huerta escolar.

Categoría: Robótica

Fecha de inicio: Miércoles 15 de Abril de 2026

Autores del proyecto:

  • Rueda Alejandro
  • Quispe Roberto

Los objetivos a realizar son:

El foco principal está en modernizar el mantenimiento de la huerta mediante la integración de hardware específico. Para esto se planea realizar la instalación técnica de diversos sensores de humedad en el terreno y llevar a cabo la configuración completa de placas controladoras Arduino.

Se busca automatizar completamente el sistema de cuidado ambiental. Esto implica el desarrollo y la programación de un ciclo de riego inteligente que responda a los datos recolectados para que las plantas reciban agua de manera eficiente.

Encargados de los archivos a crear:

  • Documentación Técnica: Rueda Alejandro
  • Esquema de Conexiones: Quispe Roberto

Recursos utilizados:

  • Repositorios de robotica
  • Documentación Arduino

Matemática Interactiva

Espacio de apoyo con actividades digitales para reforzar operaciones, lógica y resolución de problemas.

Categoría: Matemática

Fecha de inicio: Sábado 18 de Abril de 2026

Autores del proyecto:

  • Arjona Enzo
  • Flores Lucas

Los objetivos a realizar son:

Este proyecto busca modernizar el aprendizaje tradicional en una experiencia digital dinámica. El primer paso consiste en diseñar juegos de lógica que motiven a los alumnos junto con el desarrollo de una calculadora de funciones personalizada que facilite la comprensión de conceptos algebraicos complejos.

También se trabajará fuertemente en la interfaz del usuario mediante la maquetación de diversos ejercicios interactivos. El objetivo es que los estudiantes puedan practicar operaciones y resolver problemas en un entorno visualmente atractivo que refuerce su razonamiento de forma autónoma

Encargados de los archivos a crear:

  • Lógica de Operaciones: Arjona Enzo
  • Interfaz de Usuario: Flores Lucas

Recursos utilizados:

  • GeoGebra API
  • GitHub

Laboratorio Virtual de Ciencias

Propuesta para acercar experimentos y contenidos científicos a los alumnos mediante recursos virtuales.

Categoría: Ciencias

Fecha de inicio: Lunes 20 de Abril de 2026

Autores del proyecto:

  • Méndez Sofía
  • Vaca Cristian

Los objetivos a realizar son:

La propuesta central es digitalizar la experiencia de laboratorio para que sea accesible desde cualquier dispositivo. Permitiendo que los alumnos exploren estructuras biológicas que a veces son difíciles de ver en un microscopio real.

Se redactará una guía detallada de experimentos caseros seguros. El proyecto fomenta que los estudiantes apliquen el método científico en sus propios hogares utilizando materiales cotidianos.

Encargados de los archivos a crear:

  • Modelado de Simulaciones: Méndez Sofía
  • Redacción de Guías: Vaca Cristian

Recursos utilizados:

  • Simulaciones PhET
  • YouTube

Biblioteca Digital para la Escuela

Proyecto destinado a organizar materiales de estudio, lecturas y recursos académicos en formato digital.

Categoría: Educación

Fecha de inicio: Miércoles 22 de Abril de 2026

Autores del proyecto:

  • Tolaba Mex
  • Palermo Daniel

Los objetivos a realizar son:

El objetivo primordial es centralizar y democratizar el acceso al material de estudio de la institución. Se realizaran una categorización exhaustiva de libros y documentos en formato PDF, integrando además un buscador eficiente que permita filtrar los recursos según la materia o el año escolar.

Con esto se pretende organizar el flujo de lecturas y recursos académicos, garantizando que cada alumno pueda encontrar y utilizar el material que necesita para sus tareas diarias.

Encargados de los archivos a crear:

  • Base de datos de libros: Tolaba Mex
  • Maquetación del Explorador: Palermo Daniel

Recursos utilizados:

  • Internet Archive
  • GitHub
  • Wikipedia
