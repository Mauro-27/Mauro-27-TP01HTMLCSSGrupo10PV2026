Descripción primera parte:

El Trabajo practico Parte 1: HTML (HyperText Markup Language) - Semana 1 nos da las pautas para desarrollar de los primeros proyectos HTML de la carrera profesional de los estudiantes.

Los objetivos a realizar son: Iniciar el trabajo practico nro. 1 correctamente, Uso de Git y GitHub, Uso de un ide como lo es VSC.

  1. Creación de un Dashboard Principal (index.html)
  2. Creación de un Explorador de Proyectos (proyectos.html Listado)
  3. Detalle de Proyecto (detalle.html Vista Individual)
  4. Perfil de Usuario (perfil.html)

Descripción segunda parte:

El Trabajo Parte 2: Aplicación de estilos en HTML con CSS (Cascading Style Sheets) - Semana 2 agrega el conocimiento para aplicar estilos en nuestras paginas HTML.

Los objetivos a realizar son:

  1. Implementar CSS Grid para la estructura general y Flexbox para componentes internos (nav, cards, forms).
  2. Consistencia Visual: Aplicar las variables CSS (:root) para colores y tipografías.
  3. nteractividad CSS: Definir estados :hover, :focus y :active para todos los elementos interactivos.
  4. Utilizar selectores CSS para aplicar reglas de estilo utilizando clases (class) e identificadores (id) para los elementos html.
  5. Asociar el archivo CSS creado (styles.css) con el archivo HTML utilizando la etiqueta dentro de la sección < head > del archivo index.html y los demás archivos html.

Recursos utilizados:

  • GitHub
  • HTML Color Codes
  • Imagenes
